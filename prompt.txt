Domain Product:
- Buat table baru di db dengan spesifikasi dibawah

        id int auto_increment primary_key
        sku varchar(32) not null
        nama_produk varchar(64) not null
        created_at timestamp
    - Nama table: variant_product_stocks_table
        id int auto_increment primary_key
        id_product int 
        sku_variant varchar(32) not null
        stock_product uint
        price uint
        created_at timestamp

- Buat seed untuk products_table dan variant_product_stocks_table yang saling berhubungan

- Buat CRUD untuk masing masing table dalam bentuk RESTFUL API dengan body payload yang sesuai dengan isi dari table diatas.
- Standarisasi dari reseponse disesuaikan dengan response domain user
